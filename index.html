What these add-ons do

These are the major pieces added on top of stock Spire so it can be the single local emulator tool.

PEQ Editors hub

Every PHP editor tab from peqphpeditor, mapped onto local pages. Dedicated tools stay as full pages. The rest open a table editor against the same peq tables.

Items + icons

Search by name, class, race, deity, slot, and flags. Class, race, and deity chips use EQ icons. Result tables and cards show item icons and wearable class icons.

Evolving items

Targeted tables in order: define the chain in items_evolving_details, then match item columns. Type 4 is zone-kill (zone IDs in subtype, kill count in required amount).

Inventory editor

Paperdoll, bags, bank, shared bank, and parcels with item icons. Click a bag to open it, target an empty slot, place or remove items.

Zone 2D + 3D

2D map with spawn markers and placement edit. 3D Atlas loads the Lantern zone mesh, NPCs, and client scenery. Orbit, zoom, wireframe, and lighting toggles.

Server files + privacy

Point Spire at a quests folder (or HTTP host) and edit perl/lua in place. Hide private details blurs names, addresses, keys, passwords, hosts, and paths for streams.

Zone Controller

Browse configured Ultimate zone JSON (custom / ignore / depop / loot / items). Bulk create or clone zones, stamp trash/boss/raid tiers, and add custom mobs. Writes JSON only; live memory still reloads from the Perl controller.

Talents / Runewords

Edit the talent catalog, rank buckets, unlock flags, class specializations, trait vendor list, and runeword combo recipes. Preview then write JSON with backups.

Tasks, zones, chrome

Tasks use a searchable table instead of a giant native select. Zone expansions match PEQ (Classic is 1, Kunark is 2). Left-nav pages use the same windows, toolbars, and tables.

New add-ons (stills)

These shipped after the original video set. Privacy mode is on. Disk paths are hidden.

Zone Controller

Configured Ultimate zones

Reads quests/global/ultimatedata. Each row is a zone that already has controller JSON: custom mobs, ignore list, depop list, loot tables, and item kits. Links jump to the talent / unlock registries and the Perl controller.

Zone Controller

Create or clone zone JSON

Make many zone folders at once from a blank template or an existing kit. Pick which files to write (basedata, loot, items, custom, ignore, depop). Preview is dry-run; Write JSON creates backups first.

Zone Controller

Apply a trash / boss / raid tier

Stamp level, HP, and hit ranges onto a list of zone IDs. Copy basedata from a donor zone, or type new numbers. Optionally copy that donor’s loot kit. Runtime still uses basedata[type] plus custom _mod / _override.

Zone Controller

Batch custom mobs

Add named trash, boss, or raid entries across target zones. Same idea as the in-game controller’s create commands, from Spire, against the JSON files only.

Systems

Talent catalog

283 talents from talentdata/talent_catalog.json. Filter by class, edit display name, tree, ranks, cost, pool, and required talents. Preview / Write JSON. Optionally create the matching rank-registry row.

Systems

Talent rank registry

Bucket keys the server uses for spent ranks. Creating a catalog talent does not add a registry row unless you check that box. Keys follow TalentRank_<class>_<key>.

Systems

Unlock states

Spell-turned-in unlock flags next to the zone JSON. Each row is a bucket key, spell name, and expected value. These are player flags, not per-zone spawn data.

Systems

Class specializations

Per-class specializations from specializations.json: name, rank count, cost, and description. Warrior Improved Defense is shown with the same fields the server reads.

Systems

Trait vendor catalog

Non-god trait drops the vendor list uses for loot notes — not the item row itself. Item, zone, class mask, and proc. Edit and write back to vendordata.

Systems

Runeword recipes

Runtime craft is four runes plus an ethereal base. Local peq does not have the custom runeword tables yet, so Spire edits a JSON catalog. Output ID 0 means the recipe is known and the live item is not filled in. Seed writes a starter catalog from inventory.

Items

Evolving chains — targeted tables

Chain list with icons, type, max level, and problem flags. Open a chain and work two tables in order: details first (type, subtype, required amount), then the item’s evo columns. Type 4 shows zone pills from the subtype list.

Items

Evolving chain editor

The order of operations is on the page: define the chain, match the item, restart the zone. Type 99 is stock PEQ and is ignored by the server. Type 4 subtype is comma-separated zone IDs; required amount is the kill count.

Tasks

Task list redo

The old 900-row native select is gone. Search by ID or title, filter by type, and open a task from a clean table of title, type, duration, and level.

Zones

Expansion labels fixed

PEQ stores expansion as 1-based (1 = Classic, 2 = Kunark, 3 = Velious). Stock Spire treated those as 0-based, so everyone’s Kunark list showed Velious. Filter Kunark and the column now says The Ruins of Kunark.

Tools

Calculator windows

Race, class, deity, client version, expansion, augment, and inventory-slot bitmasks each sit in their own window. Click an icon or type a number — both stay in sync. Same chrome as the rest of the left nav.

Walkthrough clips

Play each clip in order, or jump to the tool you care about. Private server values stay blurred.

Editors

PEQ Editors hub

The hub lists every editor group: game data, zone/misc, and live server. Full-page tools (items, spells, zones, inventory) sit next to table editors for spawns, doors, traps, forage, and the rest. The clip scrolls the whole catalog.

Items

Item search with EQ icons

Class, race, and deity filters now carry their EQ icons. Search results keep item icons on the name, and the Classes column shows class icons instead of a long WAR, CLR list. Card view does the same for class and race. Slots and flags stay text because those have no icon set.

Items

Evolving item chains

Lists every evolution chain, each level’s item icon, max level, and whether the chain has problems. Open a chain to edit levels, types, and required amounts. The stills above show the newer targeted-table editor.

Characters

Inventory editor

Worn paperdoll, general bags, bank, shared bank, and parcels. Icons sit in the slot boxes. Click a bag to see its contents, select an empty slot, then pick an item to place it. Remove works from worn, bag, bank, and shared. Search cards also show class and race icons.

Zones

2D zone editor — Blackburrow

Blackburrow’s 2D map with walls, NPC models, doors, teleports, and zone lines. The clip pans the map, then tabs the zone card through NPCs, Items, Tasks, Sold, Spells, Zone Connections, and Zone. Edit placements can drag spawn2 rows, undo/redo, and save to the local DB. 3D Atlas and quest files are one click away.

Zones

3D Atlas — Blackburrow

Lantern zone mesh, NPC markers, and client scenery. The clip orbits the zone, zooms the camera, and toggles scenery, NPCs, wireframe, and bright lighting. Reset camera returns to the framed view. 2D map is one click away.

Server

Server file / quest editor

Connect a local folder, mounted share, or HTTP listing. The clip opens a zone quest folder, then a perl file in the syntax editor (save, reload, create new). Disk paths stay blurred. Writable trees can create and save files in place.

Server

Server config + hide private details

Tabs through World (naming, networking, key, telnet, TCP, loginservers), Zone Server, UCS, Database, and Server Files. Hide private details blurs server names, addresses, keys, passwords, hosts, and file paths so a stream or screenshot does not leak them. The switch stays on across admin pages.
